# PC全幅デザイン案

実装前の確認用デザインです。画像をページへ直接貼るのではなく、既存のHTML・CSS・画像資産で再現します。

## 前提

- 基準ページ: `test/index.html`
- SPの文言、順序、フォーム項目、FAQ、既存写真を維持する
- 「全画面」は `100vh` 固定ではなく、画面幅いっぱいの背景と中央最大1520pxの本文領域を指す
- Heroのみ1画面高を目安にし、情報量の多いセクションは自然高にする
- PC向け変更はメディアクエリ内へ置き、390pxの既存SP表示を変えない
- 紺は信頼、金は補助強調、橙は申込みCTAだけに使う

## 共通デザイン

- 紺: `#062d60`
- 金: `#c99e39`
- 淡青: `#eef5fa`
- CTA橙: `#f05a1a` を基準にした既存グラデーション
- 見出し: Noto Serif JP
- 本文・フォーム・CTA: Noto Sans JP
- 本文領域: 最大1520px（基準画像の1672px幅では左右約76px）
- PC固定CTA: Hero通過後に電話と査定導線を表示し、最終フォーム付近では内容を隠さない

## 実装時に守ること

- デザイン画像内の文字や写真を一枚画像として配信しない
- 既存のアクセシビリティ、フォーム送信、計測処理を維持する
- 既存の事例カルーセルとFAQ開閉を維持する
- 参考サイト独自の青緑・ピンク・黄色、ロゴ、実績表現、文言は使用しない
- PC化のために新しいフレームワークやスクロールスナップを導入しない
